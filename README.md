# NEXØR
## Proyecto de lengua artificial — Norma fundacional 1.0

**Creador del proyecto:** Pedro (GitHub: [@pedroboro2](https://github.com/pedroboro2))  
**Estado:** prototipo lingüístico en desarrollo  
**Versión:** 1.0 — 14 de noviembre de 2026

NEXØR es un proyecto de lengua artificial (conlang) con un sistema fonológico, una gramática y una escritura propios. Su objetivo es desarrollar una lengua coherente, aprendible y abierta a la participación de otras personas.

> **Estado de desarrollo:** esta publicación fija una primera propuesta. No debe confundirse con una lengua ya completa: el inventario de sonidos, la gramática, el léxico y el sistema gráfico requieren pruebas, documentación y revisiones sucesivas.

## Principios del proyecto

- Crear una lengua construida con reglas explícitas y consistentes.
- Separar la escritura NEXØR de la ortografía española.
- Mantener un registro de cambios para que las palabras y reglas no cambien arbitrariamente.
- Permitir que otras personas estudien el proyecto y propongan mejoras.
- No presentar NEXØR como un cifrado seguro ni como una lengua que solo una persona pueda descifrar.
