# Difusión pública de NEXØR

## Estado

El repositorio es público. La portada, el conversor y la documentación están preparados. La publicación web con GitHub Pages requiere activar el origen GitHub Actions en Settings → Pages.

No se afirma que NEXØR sea una lengua terminada ni que exista ya una comunidad externa. La difusión debe presentar el proyecto como prototipo abierto.

## Presentación breve en español

NEXØR es un proyecto abierto de lengua artificial en desarrollo. Estamos construyendo su sistema de sonidos, gramática, vocabulario y escritura geométrica propia. La documentación incluye una gramática inicial, un léxico de trabajo, ejemplos, una lámina de 36 grafemas y un conversor web experimental. Buscamos personas interesadas en lingüística, lenguas construidas, fonética, tipografía y diseño para revisar las reglas y proponer mejoras.

Repositorio: https://github.com/pedroboro2/LENGUAJE

## Short introduction in English

NEXØR is an open constructed-language project in development. It explores its own phonological system, grammar, vocabulary and geometric writing system. The repository includes a first grammar, a working lexicon, example sentences, a 36-glyph chart and an experimental web transliterator. We welcome feedback from people interested in conlangs, linguistics, phonetics, typography and writing-system design.

Project: https://github.com/pedroboro2/LENGUAJE

## Canales recomendados

1. Comunidades de lenguas construidas (conlang) y lingüística: publicar solo donde las normas permitan proyectos propios y pedir crítica técnica, no promoción repetitiva.
2. Reddit: buscar comunidades activas de conlangs y leer sus reglas antes de publicar.
3. Mastodon, Bluesky, X y LinkedIn: compartir el anuncio breve, enlazando al repositorio y mostrando la lámina de grafemas.
4. YouTube: publicar un vídeo corto explicando pronunciación, ejemplos y el conversor.
5. GitHub: mantener incidencias abiertas para propuestas concretas y registrar decisiones.

## Criterios de difusión responsable

- Identificar siempre la versión de la norma.
- Distinguir las reglas aprobadas de las hipótesis.
- No afirmar que el idioma está completo.
- No prometer privacidad ni cifrado.
- No comprar seguidores ni realizar spam.
- No publicar en comunidades sin respetar sus normas.
- No atribuir a colaboradores cambios que no hayan aceptado.

## Próximo paso de difusión

Activar GitHub Pages y comprobar que la web y el conversor funcionan en un navegador público. Después, publicar el anuncio en comunidades adecuadas y atender las primeras propuestas.
