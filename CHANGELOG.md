# Registro de cambios

## 1.0 — 2026-11-14

- Primera publicación pública de NEXØR.
- Se documenta una propuesta de inventario fonético de 36 unidades.
- Se registra un esquema gramatical inicial con orden VSO como hipótesis.
- Se incorpora un léxico de trabajo de 12 entradas.
- Se declara pendiente el diseño de la escritura y de la tipografía.

- Se rediseña la lámina SVG para reflejar los 36 grafemas del prototipo tipográfico.
- Se incorpora un flujo de despliegue automático de GitHub Pages; requiere activar Pages en la configuración del repositorio.

- Se revisa la tipografía geométrica y se añade la guía de instalación en Word.
- Se incorporan alias de teclado para las vocales con diacríticos.

- Se incorpora el manual inicial de aprendizaje, metadatos de citación, robots.txt y sitemap.xml para facilitar la publicación e indexación.

- Se añaden hoja de ruta y materiales de difusión en español e inglés.
